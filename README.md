# LAB-Z Arcade

A responsive collection of original browser games built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Open the project folder in VS Code, install the Live Server extension if needed, then right-click `index.html` and choose **Open with Live Server**. You can also open `index.html` directly in a modern browser.

## Arcade features

- Responsive navigation with a mobile menu
- Search, category filters, favorites, and recently played games
- Reduced-motion support and keyboard-visible focus states
- Seven existing playable games and LAB-Z Frontline Defense
- Frontline Defense is a playable tower-defense operation with six buildable emplacements, Campaign and Endless modes, and custom procedural battlefield visuals

All game content is maintained in `js/games.js`.
