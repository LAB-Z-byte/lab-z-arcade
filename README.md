# LAB-Z Arcade

A responsive homepage for a collection of original browser games in development. Built with plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Run locally

Open the project folder in VS Code, install the Live Server extension if needed, then right-click `index.html` and choose **Open with Live Server**. You can also open `index.html` directly in a modern browser.

## Current homepage features

- Responsive navigation with a mobile menu
- Search and category filters for the featured game lineup
- Reduced-motion support and keyboard-visible focus states
- CSS-only decorative visuals; no game artwork or playable games are included
- Every featured game is labeled **Coming Soon**

All game content is maintained in `js/games.js`.
